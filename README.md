# Rider Money — alpha

A mobile-first class prototype for app-based delivery riders in Osu, Accra, Ghana. Open `index.html` in a modern browser. No installation, build step, external assets or internet connection is needed.

## Try it
1. Review the October overview and switch to September.
2. Open Transactions → Needs review. Confirm a category and see totals change. Undo the change if needed.
3. Add a fictional cash expense for the selected month.
4. Open Tax view to inspect the fixed sample reserve and its limitations.
5. Reset demo to restore the original records.

Amounts are stored in integer pesewas. Cash left subtracts confirmed work, personal and unreviewed spending from payouts received. Own transfers are excluded. A fixed fictional reserve is then subtracted separately; it is not a Ghana tax calculation. Review items do not count as confirmed work expenses.

All records are fictional. Category suggestions simulate AI; there is no AI service, bank connection, payment or filing. Browser local storage retains demo edits where available, without syncing devices. Do not enter real financial information.

## Publish on GitHub Pages
Create or choose a repository. Put `index.html` and this README at its root. In repository Settings → Pages choose “Deploy from a branch”, then the branch containing these files and `/ (root)`, and Save. GitHub shows the live address after deployment. Share that live address with your lecturer; a repository link alone displays source rather than the app. GitHub Pages availability depends on your account and repository settings.
